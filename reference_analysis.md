# Анализ 19271.mp4

Источник: локальный файл `19271.mp4`. Данные получены через FFmpeg 9.4 из установленного CapCut; просмотрены кадры с шагом 0,5 с и сопоставлены соседние кадры (322 кадра, уменьшенные до 256×144 для расчёта разности). Контактный лист: `reference_frames/contact.jpg`.

## Технические параметры

- Кадр: 1024×576, 16:9, квадратный пиксель, H.264/yuv420p.
- Частота: 30 кадров/с; 322 декодированных кадра.
- Длительность контейнера: 10,77 с. Звуковая дорожка AAC, 44,1 кГц, стерео, 128 кбит/с.
- С 0 до примерно 6,7 с — текстовый ролик; далее — отдельная фирменная заставка TikTok. Заставка и водяные знаки не относятся к типографике цитаты и в генераторе не воспроизводятся.

## Композиция и цвет

- Фон текстовой части — практически чистый чёрный (`#000000` в крупных пустых областях).
- Основной текст — белый/светло-серый, красные слова — приглушённый насыщенный красный. Точные RGB нельзя надёжно восстановить после сжатия H.264/JPEG; рабочие приближения: `#F4F4F4` и `#BB3040`.
- Строки расположены около вертикального центра. Текстовый блок визуально центрируется целиком; однострочные фразы по центру, двухстрочные строки также центрированы отдельно.
- В исходнике сверху слева и позднее снизу справа виден водяной знак TikTok. Он не является частью выбранного графического стиля.
- Нет изображения, текстуры, рамок или движения камеры в текстовой части. Масштаб кадра постоянен.

## Типографика

- Прописные кириллические буквы с засечками, умеренная толщина штрихов. Точное семейство по сжатому видео установить нельзя; близкий доступный вариант — Times New Roman. Для режима Reference используется системный Times New Roman Regular.
- На кадре 1024×576 высота видимой буквы примерно 30–39 px в длинных фразах (около 5–7% высоты кадра). Короткие фразы выглядят немного меньше на ранних кадрах; часть разницы связана с анимацией и сжатием. Целевой кегль для генератора — около 38 px на референсном размере, с автоматическим уменьшением длинных строк.
- Между соседними строками видимый промежуток около 30–40 px; базовый шаг строк около 70 px. Межсловные пробелы обычные или слегка увеличенные. Точную кернинговую таблицу определить нельзя.
- В словах заметна лёгкая дополнительная разрядка; ориентир 1–2 px на букву при размере 1024×576.
- В примере красным выделены «МУЖЕСТВОМ», «СВОБОДЫ,» и «РАБОМ.». Цветовой акцент применяется к целым словам, не к отдельным буквам.

## Ход текста и анимация

- 0–1,4 с: первая фраза нарастает по словам: «КТО» → «КТО НЕ ОБЛАДАЕТ» → «КТО НЕ ОБЛАДАЕТ МУЖЕСТВОМ». Красное последнее слово. Шаг добавления ориентировочно 0,25–0,5 с.
- Около 1,4–4,4 с: предыдущая фраза сменяется следующей; «РИСКНУТЬ» → «РИСКНУТЬ ЖИЗНЬЮ» → «… РАДИ» → «ДОСТИЖЕНИЯ» → «… СВОЕЙ СВОБОДЫ,». Длинная фраза переносится на две строки.
- Около 4,5–6,6 с: третья фраза «ТОТ» → «ТОТ ЗАСЛУЖИВАЕТ» → «ТОТ ЗАСЛУЖИВАЕТ БЫТЬ РАБОМ.». Последнее слово красное.
- Кадровая разность показывает заметное затемнение/смену текста около 1,45, 4,55–5,1 и 6,7 с. Между добавлениями текст остаётся почти неподвижным. Появление/исчезновение выглядит как короткое плавное изменение прозрачности; точную кривую easing из сжатого источника определить нельзя.
- При добавлении слова центрируется вся обновлённая фраза, поэтому уже видимый текст меняет горизонтальную позицию. Для выбранного режима это намеренное свойство референса.
- Стандартных wipe/slide/zoom-переходов в текстовой части не обнаружено.
- Оценка длительности трёх смысловых сцен: примерно 1,4; 3,1; 2,1 с. Это приблизительно: точные границы анимации размыты.

## Звук

- Аудиодорожка существует; средняя громкость по FFmpeg `volumedetect` — −16,7 dB, пик 0 dB.
- По техническим данным нельзя достоверно назвать музыкальный жанр, темп, инструменты или отдельные звуковые эффекты. Автоматическую синхронизацию текста с битом референс не доказывает. Генератор использует равномерные тайминги; загруженную музыку добавляет независимо.

### Дополнительный анализ звука для озвучки

- Аудио активно примерно от 0 до 7,65 с; затем детектор FFmpeg (`silencedetect`, порог −30 dB, минимум 0,15 с) показывает тишину до конца файла (около 3,12 с). До 7,65 с полных тихих промежутков на этом пороге нет; фоновая музыка могла маскировать паузы речи.
- `volumedetect`: средний уровень −16,7 dB, максимум 0 dB. Это измерение всего микса, а не отдельно голоса. В первом активном фрагменте основная энергия расположена в низких и средних частотах: примерно 36% в 60–250 Гц, 50% в 250–1000 Гц, 13% в 1–4 кГц и 1% в 4–8 кГц. Проценты зависят от выбранных полос и не определяют голос.
- Точный темп произнесения, количество речевых пауз, голос диктора, компрессию и реверберацию нельзя надёжно восстановить из готового микса без отдельных дорожек. Для приближения к плотному низко-среднему балансу пресет Dramatic Narrator использует умеренный подъём баса, область разборчивости около 3 кГц, лёгкую компрессию, нормализацию и небольшой регулируемый реверберационный хвост. Тембр остаётся свойством выбранного голоса Windows.

## Решение для Reference Mode

Чёрный фон, светлый шрифт с засечками, прописные буквы, центрированный блок и красный акцент; короткое последовательное раскрытие слов с мягким появлением и исчезновением фраз. Режим по умолчанию сохраняет 16:9 и 30 FPS оригинала. Другие пропорции доступны пользователю с адаптацией компоновки. Фирменная заставка и водяной знак не копируются.
