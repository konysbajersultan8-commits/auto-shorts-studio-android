# AUTO SHORTS STUDIO

## Настольное приложение для Windows

Запустите `start_desktop.bat` двойным нажатием. Откроется отдельное окно AUTO SHORTS STUDIO; браузер и HTTP-сервер не запускаются. При первом запуске скрипт подготовит Python-окружение и установит зависимости при наличии интернета. Сборка с аудиорежимом находится в `desktop_release_audio/AUTO SHORTS STUDIO/AUTO SHORTS STUDIO.exe`.

Окно содержит генератор, встроенный предпросмотр MP4, настройки и пакетную генерацию. Музыка выбирается системным диалогом и копируется в локальную библиотеку. Рендеринг идёт в фоновом потоке; очередь можно остановить. Готовые видео получают последовательные имена `ролик 1.mp4`, `ролик 2.mp4` и далее. Результаты сохраняются в `output/` рядом с `desktop.py` при запуске через `.bat`, либо рядом с `.exe` в собранной версии.

Эмодзи в MP4 выводятся цветными через системный шрифт Segoe UI Emoji и формируются Qt/DirectWrite с поддержкой ZWJ-последовательностей, модификаторов и variation selectors. Для этого шрифт Segoe UI Emoji должен быть установлен в Windows. Эмодзи остаются в отображаемом тексте, но удаляются из текста для ElevenLabs и SAPI; изображения глифов кэшируются во время работы.

### Озвучка ElevenLabs

В разделе «Озвучка ElevenLabs» основным движком служит официальный Python SDK ElevenLabs. Ключ и Voice ID загружаются из переменных окружения или файлов `.env`, `API_KEY.env` и `.env.txt` в папке программы. Нужны `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID`; ключ не хранится в настройках приложения и не включается в сборку. В собранной папке проекта программа также читает credential-файл из корня `AUTO_SHORTS`. Если переносите только папку с `.exe`, создайте свой локальный `.env` рядом с ним. Файл `.env.txt` поддержан для текущей конфигурации проекта.

По умолчанию используется `eleven_multilingual_v2`; также доступна `eleven_flash_v2_5`. Начальная скорость речи снижена до `0.82×`; параметры голоса и движок сохраняются между запусками. В поле «Голос ElevenLabs» можно выбрать голос аккаунта: нажмите «Загрузить голоса аккаунта» (запрос только читает список и не создаёт аудио). Voice ID выбора применяется к тестовой и основной генерации и сохраняется между запусками. «Проверить подключение» выполняет только чтение метаданных настроенного голоса и доступных моделей, аудио не создаёт. Перед каждым новым платным запросом приложение показывает количество новых озвучек и приблизительное число тарифицируемых символов. При совпадении текста, Voice ID, модели и параметров аудио и временные метки берутся из локального кэша `output/.elevenlabs_cache/`.

Для синхронизации используется endpoint ElevenLabs `convert_with_timestamps`: он возвращает аудио и посимвольные метки. Приложение сопоставляет их словам после удаления тегов `[red]`, `[/red]`. В режиме «Как в референсе» целая фраза постепенно собирается по словам; ранее появившиеся слова остаются на экране до завершения фразы, затем фраза мягко уступает место следующей. Метки API управляют моментом появления слов, а длительность фразы включает фактическую паузу до начала следующей. Если API не возвращает выравнивание в точном соответствии с исходным текстом, используется оценочное распределение по словам, а приложение сохраняет отметку fallback в кэше. Музыка приглушается во время речи через FFmpeg. Скорость поддерживает диапазон 0,7–1,2; громкость, Stability, Similarity Boost, выразительность и Speaker Boost регулируются отдельно.

Windows SAPI сохранён как локальный резервный движок без API. Для него доступны выбор установленных голосов, обработка Dramatic Narrator и паузы между фразами. Если русский голос SAPI отсутствует, установите компонент «Речь» для русского языка в настройках Windows.

Нажатие «Тест озвучки» создаёт `output/voice_test.mp3` только после подтверждения запроса в окне приложения. Тесты интерфейса и автоматические тесты ElevenLabs используют фиктивный SDK и не списывают кредиты.

### Аудиозапись для публикаций с фотографиями

В разделе «Аудиозапись» можно отдельно создать аудиофайл без видеокадров и MP4. Введите текст, выберите ElevenLabs или установленный голос Windows SAPI, укажите скорость, обработку, паузы и формат MP3/WAV. Можно добавить локальную музыку через системный диалог: выберите, зацикливать ли короткий трек, или позволить ему закончиться раньше речи. FFmpeg плавно введёт и завершит музыку и при включённой настройке автоматически приглушит её под голосом. Речь формируется по предложениям; межфразовые паузы и длительность голосовых фрагментов сохраняются при сведении. Настройка реверберации добавляет лёгкий отражённый хвост, но не меняет высоту голоса и сама по себе не делает синтез натуральнее.

«Прослушать голос» создаёт временный WAV без музыки. «Создать аудиозапись» сохраняет итоговый микс в `output/Аудиозапись N.mp3` или `.wav`, где номер последовательно выбирается среди файлов обоих форматов. Доступны прогресс, остановка, воспроизведение результата и повторное открытие файла. Создание выполняется в фоновом потоке; видеорендерер не запускается.

Фотография не содержит данных, по которым можно определить голос. AUTO SHORTS STUDIO пока не создаёт голоса по текстовому описанию и не выполняет клонирование из своего интерфейса. Выберите существующий Voice ID; новый голос, созданный отдельно в ElevenLabs, можно выбрать после обновления списка. Клонируйте только запись, на которую у вас есть разрешение владельца. Программа не определяет голос по фотографии.

Для TikTok перенесите MP3/WAV на телефон или откройте файл в поддерживаемом приложении и выберите его в добавлении звука, если эта опция доступна для фото-публикации в вашей версии TikTok. Если приложение не принимает готовую аудиозапись напрямую, используйте предложенный TikTok способ выбора звука. Этот режим программы экспортирует только аудио; сам TikTok может требовать подготовить фото-публикацию отдельно.

Для самостоятельной сборки запустите `build_desktop.bat`. Результат создаётся в `desktop_release_visual_engine/AUTO SHORTS STUDIO/`; переносите всю папку целиком. Если в проекте есть `bin/ffmpeg.exe`, скрипт включает его в собранное приложение. В текущей сборке рядом с программой лежит FFmpeg 9.0.1 essentials (статический x64, H.264/AAC). Его лицензия и сведения о сборке находятся в `bin/FFmpeg-LICENSE.txt` и `bin/FFmpeg-README.txt`. Ключ и Voice ID не входят в сборку: задайте переменные окружения или создайте `.env` рядом с `.exe`. Если FFmpeg отсутствует в папке приложения, PATH или типовых папках, нажмите «Указать FFmpeg…» в левом меню; путь запоминается для следующих запусков. Альтернативно задайте переменную `AUTO_SHORTS_FFMPEG`.

## Веб-версия

Рабочая веб-версия сохранена. Её по-прежнему можно запустить через `start.bat`.

Локальное приложение для создания коротких типографических MP4 из текста. Русский интерфейс, ручной акцент `[red]...[/red]`, загрузка MP3/WAV, пакетная обработка TXT/CSV/JSON, 30/60 FPS и три формата кадра. Интернет и платные API для генерации не нужны.

В «Настройках» доступны длительность и задержка сцены, скорость, прозрачность, масштаб и смещение текста, цвета, шрифт, уровень музыки и плавные аудиопереходы. Экспериментальная привязка появления слов к энергетическим акцентам музыки включается отдельно; если заметных акцентов мало, используются равномерные тайминги.

## Визуальный движок 2.0

В разделе «Визуальный стиль» доступны независимые эффекты появления, удержания и исчезновения с регулировками скорости, интенсивности, плавности и длительности перехода. Библиотека анимаций: Fade In, Typewriter, Word by Word, Letter by Letter, Slide Up/Down/Left/Right, Zoom In/Out, Pop, Blur Reveal, Mask Reveal, Glitch, Flicker, Subtle Pulse, Floating, Shake, Highlight Sweep и Karaoke Highlight. Karaoke Highlight использует временные метки речи, если они есть. Старые анимации остаются доступными.

Есть 15 встроенных типов фона: Pure Black, Dark Gray, White Minimal, Deep Navy, Black Gradient, Moving Gradient, Film Grain, Floating Particles, Dark Smoke, Soft Light, Vignette Pulse, Digital Noise, Grid Motion, Abstract Waves и Subtle Red Glow. Для пользовательских фонов поддерживаются JPG, PNG, WEBP, BMP, MP4, MOV, WEBM, MKV и AVI. Видео автоматически обрезается под выбранный кадр, зацикливается без звука и может быть затемнено, размыто, осветлено, настроено по контрасту и окрашено выбранным оттенком. Миниатюра и предпросмотр отражают оттенок; он сохраняется в пользовательских пресетах и применяется в пакетном рендере. Короткий видеоклип для фона повторяется FFmpeg до конца рендера.

Выбор шрифта содержит 15 системных шрифтов Windows с кириллическими начертаниями и файлы TTF/OTF/TTC из папки `fonts/` рядом с программой. Можно добавлять собственные файлы шрифтов и выбирать их кнопкой «Обзор…». В визуальных настройках управляются размер, полужирное начертание, межбуквенный и межстрочный интервалы, выравнивание, тень, обводка, прозрачность и цвета. Цветные эмодзи сохраняются в кадре и продолжают синхронизироваться с речью.

Встроены пресеты CLASSIC DARK, CINEMATIC, LUXURY, AGGRESSIVE, PHILOSOPHY, MOTIVATION, GLITCH, CLEAN WHITE, DARK RED и FUTURISTIC. Они задают стиль текста, цвета, фон и переходы; пользовательские пресеты сохраняются в настройках Windows. Предпросмотр показывает короткую анимацию на тестовой фразе без обращения к ElevenLabs. В пакетном разделе можно использовать настройки генератора, случайно выбирать отмеченные пресеты или чередовать их; имя стиля включается в CSV-отчёт.

При первом запуске выбран пресет CLASSIC DARK: чёрный фон, Times New Roman, белые заглавные буквы с красными акцентами и сборка фразы по словам. Формат по умолчанию — вертикальный 9:16, скорость ElevenLabs — `0.82×`, а текст расположен немного выше центра, как в приложенном референсе. Остальные пресеты и параметры остаются доступными.

## Запуск на Windows

1. Дважды нажмите `start_desktop.bat` для настольного приложения. Оно работает в отдельном окне.
2. В разделе «Генератор» создаются видео MP4; в «Аудиозапись» — только MP3/WAV без видеокадров.
3. Для музыки выберите MP3/WAV в соответствующем разделе. Для пакета видео откройте «Пакетная генерация» и выберите файл; CSV-отчёт сохраняется рядом с результатами.
4. Веб-версия остаётся доступна отдельно через `start.bat` и открывается в браузере по адресу `http://127.0.0.1:8765`.

## Android (облачная сборка)

В репозитории добавлен отдельный touch-интерфейс из `main.py` и `android_app/`. Он использует существующие модули видео- и аудиогенерации, а сборка планируется на облачном Ubuntu runner в GitHub Actions. На Windows-компьютер ставить Linux, WSL, Android Studio или SDK не требуется. APK должен появиться во вкладке **Actions → Android APK → Artifacts** после успешной сборки; локально установленный Android APK здесь пока не приложен.

На телефоне видео и аудио должны сохраняться в закрытую папку данных приложения. Для ElevenLabs ключ и Voice ID вводятся в интерфейсе; ключ держится только в памяти до закрытия APK и не встраивается в исходный код. Голос ElevenLabs и обработка через FFmpeg требуют интернет-доступа к ElevenLabs для синтеза и совместимого FFmpeg для сведения/кодирования. Windows SAPI в Android недоступен. Публичный GitHub-репозиторий содержит только исходный код: API-ключи, медиа пользователя и Windows-бинарник FFmpeg туда не загружаются.

Android-экран не является подтверждённой заменой Windows-сборки, пока APK не собран, установлен и не проверен на устройстве. В частности, Android-версия FFmpeg должна быть включена в APK и проверена вместе с H.264, MP3/WAV и выбором файлов; до прохождения этого теста мобильный экспорт не считается готовым. Из-за открытой видимости репозитория не помещайте туда приватные ключи, фотографии, музыку или записи.

Приложение слушает только `127.0.0.1`, файлы не загружаются во внешние сервисы. Закройте консоль, чтобы остановить приложение.

## Зависимости

Для запуска из исходников нужны Python 3.11+, Pillow, NumPy и FFmpeg с H.264 и AAC. `start.bat` создаёт `.venv` и пытается установить недостающие Python-пакеты. FFmpeg из папки проекта `bin/`, PATH или типовых папок будет найден автоматически; можно задать `AUTO_SHORTS_FFMPEG` с путём к `ffmpeg.exe`.

Приложение проверяет доступные H.264-кодеры и выбирает рабочий; если аппаратные кодеры недоступны, использует `libx264` или `h264_mf`. Если FFmpeg был доступен через CapCut и CapCut удалили, укажите другой `ffmpeg.exe` кнопкой слева; программа сохранит его путь в пользовательском профиле Windows. Отдельный `ffprobe` не обязателен для работы; видео можно проверить командой `ffmpeg -i файл.mp4 -f null NUL`.

## Режим референса

Анализ исходного ролика — в [reference_analysis.md](reference_analysis.md), кадры — в `reference_frames/`. Режим воспроизводит чёрный фон, центрированную белую типографику с засечками, красное выделение и последовательное раскрытие слов. Водяной знак и TikTok-заставка исходного файла не копируются. Исходное видео горизонтальное 16:9; другие форматы адаптируют композицию.

## Формат файлов для пакета

- TXT: одна цитата на строку.
- CSV: цитаты в первом столбце, необязательный заголовок `quote`, `text`, `цитата` или `текст`.
- JSON: массив строк либо объектов с полем `text` или `quote`.

Ограничение: до 500 цитат за запуск; одна цитата — до 5000 символов. Прерывание завершает текущий рендер и сохраняет CSV-отчёт по уже обработанным цитатам.

## Дополнительно

Быстрый просмотр создаёт 1024×576 независимо от выбранного формата. Для итогового экспорта выключите его. По умолчанию музыка не добавляется; без аудиофайла MP4 содержит только видеодорожку.
